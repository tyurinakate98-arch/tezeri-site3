# ТЕЗЕРИ — обновлённый макет сайта

В архиве 12 содержательных страниц и 404. В корне находится index.html. Сайт работает без установки пакетов: распакуйте и откройте index.html. Соседние файлы и assets должны остаться рядом.

## Посмотреть через GitHub Pages

1. Загрузите содержимое архива в корень репозитория GitHub. Нужны также папки assets, tools и .github.
2. Откройте Settings → Pages. В Source выберите GitHub Actions.
3. В Actions запустите Publish TEZERI preview, если публикация не началась после загрузки в main.
4. После успешного выполнения ссылка появится в Settings → Pages и в результате действия Deploy.

Workflow берёт настоящий адрес Pages из GitHub и готовит canonical, sitemap.xml, robots.txt, Open Graph и JSON-LD. Проектный префикс вида /repository/ сохраняется. Локально Python и Node для просмотра не нужны.

Можно использовать обычную публикацию из ветки main / root: статические страницы тоже будут работать, но автоматическая подготовка SEO в таком режиме не запускается.

## Индексирование

По умолчанию это предварительная версия: страницы содержат noindex. Это не закрывает сайт паролем, а только даёт поисковикам указание не включать макет в выдачу.

После готовности коммерческих условий, регистрации, контактов и политики обработки данных создайте переменную репозитория PUBLIC_INDEXING со значением true в Settings → Secrets and variables → Actions → Variables. Повторно запустите workflow. Он откроет индексирование содержательных страниц; 404 останется noindex.

Для другого хостинга используйте: python tools/configure_seo.py --root . --site-url ВАШ_HTTPS_АДРЕС. Ключ --public открывает индексирование. Скрипт не обращается к сети.

Порядок workflow сверён с [официальной документацией GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages). Сам запуск в вашем репозитории здесь не выполнялся.

## Что подготовлено

- Главная с настоящим продуктом в первом экране, отдельными сценами материалов и денег, анимацией 4 → 1 и горизонтальной сменой двух направлений на компьютере.
- Страницы остекления, балконов, 3D и расчёта, материалов, управленческого учёта, перехода от таблиц и пробного периода.
- База знаний и три инструкции по реальной документации.
- Мобильное меню, выбор экранов без двух горизонтальных прокруток, просмотр изображения в диалоге с Escape и возвратом фокуса.
- Адаптивные изображения, WOFF2, локальные шрифты, обычные HTML-ссылки и уникальные названия страниц.
- При reduced motion содержание остаётся доступным без удержания прокрутки.

## Что ещё требуется для продаж

- Настоящий адрес регистрации и подключение чата поддержки.
- Утверждённая цена, состав подписки после пробы и юридические сведения разработчика, условия и политика обработки данных.
- Ребрендинг самой программы и новые материалы с названием ТЕЗЕРИ. Исходники ERP не входят в этот архив; её интерфейс здесь не менялся.
- Самостоятельный объект квартиры, дома либо террасы для первого направления. Сейчас использован подлинный инструмент конструкций на примере балкона, это прямо подписано.
- Яндекс Вебмастер, Search Console и реальные счётчики/события после выбора домена и получения идентификаторов. В site.js есть локальные события tezeri:event; фактическая отправка аналитики не подключена. Событие клика не считается регистрацией, активацией или оплатой.
- Проверка частотности запросов в Wordstat и выдачи. Структура страниц подготовлена по намерениям пользователей; объёмы спроса не измерены.

Третье направление не раскрыто. Выдуманных отзывов, результатов клиентов и цен нет. Настоящие скриншоты не перекрашивались; значения и поведение ERP не подменялись учебным виджетом.

## Где править

Тексты — соответствующий HTML. Внешний вид — site.css. Взаимодействия — site.js. Экраны и видео — assets/media. Метаописания для генератора SEO — page-manifest.json и head соответствующей страницы.

Сохраните отдельную копию перед заменой первичных материалов. Все файлы в этом архиве относятся к новому макету; старый архив проекта не изменялся.
